# Amplio releases

This repository is the public download and automatic-update channel for the
Amplio desktop app. Releases contain signed installers, updater manifests,
checksums, and release notes only.

Amplio source code and build credentials are not stored here. Release assets
are produced by the private product repository and published through a
restricted GitHub Actions environment.

Download the current version from [Releases](../../releases/latest).

## Security

Only install artifacts published under this repository's Releases page. Report
a suspected security issue privately to the Amplio team. Do not open a public
issue with credentials or sensitive logs.
